Ford Retain 🚘

Sistema inteligente de retenção para o pós-venda Ford, desenvolvido para auxiliar concessionárias e equipes de atendimento a identificar clientes com risco de abandono e aumentar o retorno para revisões e serviços.

📌 Sobre o projeto

O Ford Retain é uma plataforma desenvolvida para monitorar clientes e veículos Ford, analisando fatores como:

Quilometragem
Tempo desde a última revisão
Garantia
Histórico de manutenção
Risco de abandono

O sistema organiza os clientes em níveis de risco:

🔴 Alto risco

🟡 Médio risco

🟢 Baixo risco

permitindo que a equipe de pós-venda tome ações preventivas de forma rápida e inteligente.

🎯 Objetivo

A proposta do projeto é melhorar a retenção de clientes no pós-venda Ford através de uma interface moderna, intuitiva e inteligente.
